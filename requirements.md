* New requirements
  * Handling rangeIncludes selection when there is more than one rangeIncludes values
    * Background: The CEDS Ontology has object properties that can point to base classes, meaning we'd want to be able to specify which of the base or child classes in that class structure to use in the SHACL contraints.  For instance, the following SHACL cannot be generated by this tool:

    ceds:K12StaffEmploymentShape a sh:NodeShape ;
    sh:closed true ;
    sh:ignoredProperties ( rdf:type rdf:id rdf:value rdfs:label ceds:id ) ;
    sh:property ceds:EmploymentEndDateShape,
        ceds:hasMembershipRelationshipShape ;
    sh:targetClass ceds:C200208 .

    ceds:hasMembershipRelationshipShape a sh:PropertyShape ;
        sh:class ceds:C200207 ;
        sh:node ceds:K12StaffAssignmentShape ;
        sh:path ceds:P600549 .

    In this case, hasMembershipRelationship (object property ceds:C200207) has a rangeIncluds of "Membership," which is the base class for several child classes.  We need to be able to specify which of these child classes we want to use directly in this tool. The technical requirements are listed below. 
    * Techncial Requirements: 
      * When selecting an object property in the tool, the code much interrogate the class in the rangeIncludes to see if it is a parent class.  
      * If it is a parent class:
        * We need to enable a multiselect list that allows the user to specify which of those classes, including the parent class and all child classes in the hierarchy, the user wants to enable.
        * In the output, each of the selected classes needs to be added in a SHACL sh:or construct to enable that selection.  Here is an example of the output:

        cepi:hasK12StaffAssignmentOrganizationShape a sh:PropertyShape ;
            sh:or (
                [ sh:class ceds:C200239 ]
                [ sh:class ceds:C200074 ]
                [ sh:class ceds:C200315 ]
            ) ;
            sh:node ceds:OrganizationShape ;
            sh:nodeKind sh:BlankNodeOrIRI ;
            sh:path ceds:P600062 .  

    * If it is not a parent class, automatically use the specified rangeIncludes as the "sh:class" value like so:

    ceds:hasMembershipRelationshipShape a sh:PropertyShape ;
        sh:class ceds:C200207 ;
        sh:node ceds:MembershipShape ;
        sh:path ceds:P600549 .
